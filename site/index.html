Install the standalone application

Start locally with Python 3.11+

Project Brain and the inspection, skill, importer, adapter, and MCP features do not require Git or Docker. Executing restore drills additionally requires Linux, Docker Engine, and Docker Compose v2.

uv tool install "git+https://github.com/Someone006/Restore-Rehearsal.git@v0.3.0"
rehearse --version

Prefer pipx? Clone the source and run pipx install .. Read the complete documentation before configuring a restore recipe.

Private by design

Project evidence stays local.

Rehearse collects no telemetry and does not upload project data, reports, screenshots, or backup contents. Its offline Project Brain visual uses no remote scripts, fonts, analytics, or network requests.

API keys, credentials, tokens, private keys, and backup contents must never be uploaded. Any other outbound project information requires the user’s explicit destination and scope consent.

Plain answers

Frequently asked questions

Does Project Brain require a Git repository?

No. It can statically scan a Git work tree or an ordinary local folder. Git-aware ignore behavior is used when Git is present.

Does the project scan execute my code?

No. Project Brain performs a bounded static scan. Restore drills are different: they execute only the reviewed commands declared in a recipe inside a disposable Docker Compose environment.

Is Restore Rehearsal backup software?

No. It does not create or replace backups. It tests a declared backup and recovery path so that the existence of a backup is not mistaken for evidence that recovery works.

Can companies use it?

Yes. Apache-2.0 permits commercial use. The current release is alpha and should be treated as an advisory tool with human review, not a sole production or compliance control.
