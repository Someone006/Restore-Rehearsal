# Native and mobile inspection

Use a disposable profile, emulator, simulator, or test workspace. Record app version, platform,
window/device dimensions, scale, theme, locale, input method, permissions, and connectivity state.
Inspect menus, keyboard order, resize behavior, system dialogs, offline/error states, and recovery.

Avoid notification centers, unrelated windows, real contacts, camera rolls, clipboards, and account
data in captures. Do not grant broad device permissions merely to make a test pass.
