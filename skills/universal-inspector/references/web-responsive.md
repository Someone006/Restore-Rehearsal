# Web and responsive inspection

Inspect the rendered accessibility tree and console/network failures before clicking. Test a small
viewport set that represents phone, tablet, and desktop rather than arbitrary device branding.
Check keyboard navigation, focus, zoom/reflow, reduced motion, color schemes, loading, empty, error,
and authenticated/unauthenticated states where relevant.

Take screenshots only after layout settles; record URL, viewport, pixel ratio, theme, locale, and
state. Never use real payment, production, or personal data for an interaction test.
