# Targets and evidence

Create a small matrix: target, user claim, initial state, action, expected observation, evidence,
and cleanup. Test the highest-risk claim first. Record exact versions and dimensions without
absolute private paths or environment dumps.

Prefer layered evidence: semantic structure or machine result, focused visual capture, and a
reproducible action. Distinguish observed facts from interpretation. A missing tool or inaccessible
state is a limitation, not a passing result.
