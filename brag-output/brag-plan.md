# Brag Plan: Restore Rehearsal

## What is this app?

Restore Rehearsal is a local-first command-line application that maps any software or digital
project into a private Project Brain and tests declared backups inside disposable Docker Compose
restore and upgrade drills.

## The angle

Evidence over promises. The film begins with the uncomfortable gap between owning a backup and
knowing it restores, then connects that recovery question to the other thing teams and AI agents
often lack: a trustworthy map of the whole project. The visual story turns a local folder into a
connected graph, turns a backup into a checked disposable stack, and resolves both into one private
`.rrbrain` evidence file.

## Hook (first 2-3 seconds)

On the project's dark green ground, the line **“Backups are promises.”** appears with restrained
weight. **“Restores are proof.”** lands beneath it in mint at the first decisive musical turn.

## Key moments (the middle)

- A real command, `rehearse brain build . --output project.rrbrain`, creates a focused architecture
  graph with project, dependency, test, deployment, and recovery nodes.
- A backup moves into a clearly labelled disposable stack; three grounded checks resolve in order:
  restore, verify, upgrade.
- The many evidence paths collapse into **one private `.rrbrain` file**, with architecture, change
  impact, and recovery evidence remaining visibly connected.

## Outro / punchline

**Know your project. Prove it can recover.** The product name and public project URL hold long
enough to read, with the required music credit visible.

## User flow worth showing

Scan a local project → build and inspect its connected Project Brain → run an isolated restore and
upgrade drill → retain bounded evidence for the next person or AI agent.

- Interpretation: measured cuts, generous holds, precise terminal and graph motion, restrained
