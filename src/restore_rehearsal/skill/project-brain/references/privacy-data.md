# Privacy and Data Governance

Lens ID: `privacy-data`

Map declared data stores, forms, API fields, analytics/dependency surfaces, logs, and privacy/
retention/deletion/export documentation. Flag possible personal-data flows, unclear lifecycle,
over-collection, or log exposure only as evidence-backed review points.

Recommend inventory, minimization, redaction tests, deletion/export verification, retention checks,
and qualified privacy review. Never infer legal status, process personal data, or certify compliance.
The [NIST Privacy Framework](https://www.nist.gov/privacy-framework) is a useful reference.
