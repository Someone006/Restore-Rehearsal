# Security and Supply Chain

Lens ID: `security-supply-chain`

Review trust boundaries, auth surfaces, container privileges, sensitive-looking tracked paths,
workflow pinning, lockfiles, dependency evidence, SBOMs, and release provenance. Use the
[OpenSSF OSPS Baseline](https://baseline.openssf.org/) and
[NIST SSDF](https://csrc.nist.gov/pubs/sp/800/218/final) as reference points.

Propose negative authorization tests, secret scanning, least-privilege configuration, dependency
review, and provenance checks. Never expose a suspected secret while reporting it.
