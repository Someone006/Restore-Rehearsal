# Accessibility and Design System

Lens ID: `accessibility-design`

Review static HTML semantics, accessible names, keyboard/focus evidence, color/token usage,
responsive states, components, and accessibility test output. Use the
[WCAG 2.2 Recommendation](https://www.w3.org/TR/WCAG22/) as the reference baseline.

Propose automated checks plus keyboard, screen-reader, zoom/reflow, contrast, and visual-regression
tests. Static rules cover only a subset; never claim conformance without a complete evaluation.
