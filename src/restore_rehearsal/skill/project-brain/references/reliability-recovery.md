# Reliability and Recovery

Lens ID: `reliability-recovery`

Review services, volumes, managed-data dependencies, health checks, migrations, runbooks, Rehearse
recipes, and imported run evidence. Flag state without a tested restore path, weak readiness,
stale/missing drills, and managed-service assumptions.

For managed databases, request ownership, provider backup/restore method, retention, RPO/RTO,
export portability, and real restore-drill evidence. Never say Rehearse restored a provider service
unless an adapter and report prove it.
