# Code, documents, and data

For code, connect a claim to symbols, dependencies, tests, and executed evidence; do not infer
behavior from a screenshot. For documents, inspect structure, headings, reading order, links,
tables, pagination, export fidelity, and redaction. For datasets, inspect schema, types, constraints,
nulls, duplicates, bounds, lineage, and small synthetic samples—not raw customer rows.

Use visualizations only when they expose a meaningful relationship. Preserve the original artifact
and write derived evidence separately.
