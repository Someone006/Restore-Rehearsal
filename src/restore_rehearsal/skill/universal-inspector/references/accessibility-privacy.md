# Accessibility and privacy across surfaces

Check names, roles, states, focus order, keyboard access, contrast, scaling, motion, error recovery,
and assistive-technology output appropriate to the surface. Static or automated checks cover only a
subset; never claim conformance without a complete evaluation.

Before capture, minimize the visible surface and close unrelated content. Treat screenshots,
recordings, DOM/accessibility trees, logs, API payloads, and terminal output as project data. Keep
them local with restricted access and a stated retention/deletion plan.
