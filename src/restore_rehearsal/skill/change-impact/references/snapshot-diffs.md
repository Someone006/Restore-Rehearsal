# Snapshot diffs

Choose snapshots by stable identifier and record both semantic digests. Classify nodes, edges, and
findings as added, removed, or modified; a rename can appear as remove plus add unless independent
evidence links the identities. Duplicate builds may intentionally produce no new snapshot.

Treat truncation, missing parsers, ignored paths, and unsupported binaries as explicit uncertainty.
Never describe an absent graph edge as proof that no dependency exists.
