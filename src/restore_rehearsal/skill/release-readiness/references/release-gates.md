# Release gates

Require clean source status; version/tag agreement; passing supported-platform, installed-package,
integration, and recovery checks; reviewed changelog and migration notes; private-data scan;
checksums/SBOM/provenance; documented compatibility and support; and rollback/revocation steps.

Record unavailable external settings—trusted publishing, protected environments, branch rules,
registry visibility, signing identity, or notarization—as blockers, not successful gates.
