# Restore Rehearsal v0.3.0

Restore Rehearsal is an open-source, local-first tool for two connected jobs:

1. **Backup restore testing** — restore a declared backup into a disposable Docker Compose stack,
   verify it, rehearse a candidate upgrade, keep share-safe evidence, and remove the stack.
2. **Private Project Brain** — statically scan any dedicated project folder, with or without Git,
   into one local `.rrbrain` SQLite file for architecture, dependencies, tests, deployment,
   recovery evidence, findings, decisions, failed attempts, and structural history.

This is an **alpha prerelease**. It can be used in commercial projects under Apache-2.0, but it
must not be the sole production release gate, disaster-recovery control, security assessment,
accessibility certification, or legal/compliance decision.

## Highlights

- Scan websites, native apps, CLIs, APIs, documentation, data projects, infrastructure folders,
  source repositories, and mixed local projects without executing their code.
- Explore Graph, Changes, Findings, Recovery, Evidence, and Timeline views in a self-contained
  offline visualization with no remote scripts, fonts, analytics, or network requests.
- Query focused context, relationship-derived change impact, relevant tests, memories, and prior
  recovery evidence from the command line or the local read-only-by-default MCP server.
- Import bounded evidence from SARIF, CycloneDX/SPDX, JUnit, LCOV/Cobertura, OpenAPI, Terraform,
  Kubernetes, and CI artifacts while discarding secrets and high-risk raw content.
- Install nine portable Agent Skills for Project Brain, safe initialization, universal inspection,
  change impact, evidence import, recovery adapters, restore rehearsals, release readiness, and
  plugin authoring.
- Propose non-executing recovery adapters for PostgreSQL, MySQL/MariaDB, SQLite, MongoDB,
  object-storage exports, and managed-service export handoffs.

## Install

Python 3.11 or newer is required. Project Brain, inspection, imports, skills, adapters, and MCP do
not require Git or Docker. Executing restore drills additionally requires Linux, Docker Engine,
and Docker Compose v2.

```console
uv tool install "git+https://github.com/Someone006/Restore-Rehearsal.git@v0.3.0"
rehearse --version
```

The release also includes a universal wheel, source distribution, fully hashed Homebrew formula,
CycloneDX and SPDX SBOMs, and `SHA256SUMS`.

## Privacy and safety

Restore Rehearsal collects no telemetry and does not upload project data, reports, screenshots, or
backup contents. API keys, credentials, tokens, private keys, and backup contents must never be
uploaded. Any other outbound project, report, screenshot, personal, or customer information
requires explicit user approval for a named destination and scope.

Restore drills execute only reviewed commands declared in a recipe and require an isolated,
disposable environment. Read the
[safety model](https://github.com/Someone006/Restore-Rehearsal/blob/main/docs/safety.md) before
configuring a drill.
